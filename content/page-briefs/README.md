# Sunbright Page Briefs

Each page has a brief (this folder) → final copy gets written in `src/content/pages/` in the new `Sunbright-Recovery` repo during Phase 4 of execution.

Brief format:
- **URL**
- **Primary keyword** + secondary keywords
- **H1** (human, not clinical)
- **Meta title** (50–60 chars)
- **Meta description** (150–160 chars)
- **Target word count**
- **Sections** (H2 outline)
- **CTAs** (primary + secondary)
- **Schema types**
- **Internal links** (where to link to/from)
- **Notes** (anything special for Linda to weigh in on)
