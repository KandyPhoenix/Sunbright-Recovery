# Sunbright Recovery Center

Official website for **Sunbright Recovery Center** — a faith-integrated, evidence-based addiction recovery facility in Northern California. Sunbright operates under the **Parish Health and Wellness (PHW Care)** umbrella.

🌐 **Live site:** [sunbrightrecovery.com](https://sunbrightrecovery.com) *(coming soon)*

## About

Sunbright Recovery Center offers three levels of care for individuals and families navigating addiction:

- **Residential / Inpatient Rehab** — 30, 60, and 90-day programs
- **Intensive Outpatient (IOP) & Partial Hospitalization (PHP)**
- **Sober Living & Aftercare**

Founded by **Linda Spyres, LCSW, LAADC-CA** — 20+ years of specialized addiction treatment experience. Medi-Cal and most major insurance accepted; sliding scale available.

## Tech Stack

- **[Astro](https://astro.build)** — static site generator
- **[Tailwind CSS](https://tailwindcss.com)** — utility-first CSS
- **[Vercel](https://vercel.com)** — hosting + auto-deploy
- **Markdown** content via Astro Content Collections

## Development

```bash
# Install
npm install

# Start dev server (http://localhost:4321)
npm run dev

# Type check
npm run astro check

# Production build
npm run build

# Preview production build locally
npm run preview
```
